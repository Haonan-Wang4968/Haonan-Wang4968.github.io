## Project question

How can an existing follow-up application reduce the manual work of transferring handwritten notes and reports into structured records?

## My contributions

- Built an asynchronous handwriting recognition pipeline with Redis caching.
- Implemented language-model-based extraction of structured fields from follow-up reports and worked with clinicians to align the outputs with their workflow.

## Reported project result

The handwriting recognition pipeline reduced manual data entry by 70% in the project.
